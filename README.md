# Sustainability Implementation in Software Engineering: A Systematic Review of Cross-Level Mechanisms

This repository contains supplementary materials for a systematic literature review of sustainability implementation in software engineering. The review analyzed 39 studies to identify implementation mechanisms and reported relationships across organizational levels.

The repository provides:

- Excel with article information and extracted data
- Coding method
- Search strings
- Selection criteria and PRISMA 

The materials support transparency and reproducibility of the research.
