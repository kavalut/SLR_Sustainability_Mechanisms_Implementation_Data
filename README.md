# SLR_Sustainability_Mechanisms_Implementation_Data
Supplementary materials and extracted data for a systematic literature review of sustainability implementation mechanisms and their relationships across organizational levels in software engineering.

# Sustainability Implementation in Software Engineering: A Systematic Literature Review

This repository contains supplementary materials for a systematic literature review of sustainability implementation in software engineering. The review analyzes 39 studies to identify implementation mechanisms and reported relationships across organizational levels.

The repository provides the search strategy, study selection criteria, extracted findings, and analytical classification used in the review. The materials support transparency and reproducibility of the research.
